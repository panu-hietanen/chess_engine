A chess game written in C.

All my own code using only the C standard library and raylib for rendering the board.

This is a work in progress, however almost all the features of chess are implemented. I believe that only the following is missing:

- 50 move rule
- 3 move repetition

At some point I will also implement move history and material tracking.

The end goal of this project is to use my custom machine learning library to perform board evaluation or even to create a chess bot.
